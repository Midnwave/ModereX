Overview

Welcome to the ModereX Control Panel - your comprehensive server moderation hub. This web-based interface allows you to manage players, punishments, automod rules, and monitor server activity in real-time.

Key Features

  • Real-time Sync - Changes reflect instantly on the server
  • Multi-device Access - Access from any device with a browser
  • Secure Authentication - Token-based access with in-game linking
  • Full Moderation Suite - Bans, mutes, warnings, kicks with evidence
  • Activity Logging - Complete audit trail of all actions
Dashboard screenshot placeholder

Security & Authentication

How Authentication Works

The ModereX panel uses a secure token-based authentication system. When you first access the panel, you'll receive a unique authentication token that you must enter in-game using /mx link <token>. This links your Minecraft account to the panel session.

Never share your authentication token!

Anyone with your token can access the panel as you. Tokens are single-use and expire after linking.

Lost Access / Token Issues

  1. Close all browser tabs with the panel open
  2. Clear your browser's local storage for this site
  3. Navigate to the panel URL again to get a new token
  4. Link the new token in-game with /mx link

Trusted Devices

Your session is saved as a "trusted device" after successful authentication. You can manage trusted devices in My Settings to revoke access from other devices.

Authentication flow screenshot placeholder

Dashboard

The Dashboard provides a real-time overview of your server's moderation status. Here you'll find key statistics, recent activity, and quick access to common actions.

Statistics Cards

  • Online Players - Current player count (click to view player list)
  • Active Bans - Number of currently active bans
  • Active Mutes - Number of currently active mutes
  • Recent Warnings - Warnings issued in the last 24 hours

Activity Feed

The activity feed shows real-time events including player joins/leaves, punishments issued, automod triggers, and staff actions. Click on any event to view more details.

Dashboard stats screenshot placeholder

Player Management

The Player Management page allows you to view all players, their punishment history, and take moderation actions.

Viewing Player Details

Click on any player to view their complete profile including:

  • UUID and IP address (if you have permission)
  • Current punishment status (banned, muted, warned)
  • Full punishment history
  • Recent chat and command logs
  • Session history (join/leave times)

Taking Actions

From the player detail view, you can:

  • Issue punishments (ban, mute, warn, kick)
  • Add to/remove from watchlist
  • View evidence attached to punishments
  • Revoke active punishments
Player detail screenshot placeholder

Punishments

The Punishments page displays all punishments issued on the server with filtering and search capabilities.

Punishment Types

  • Ban - Prevents player from joining the server
  • IP Ban - Prevents all connections from an IP address
  • Mute - Prevents player from chatting
  • Warn - Issues a warning (can auto-escalate to ban)
  • Kick - Immediately disconnects the player

Attaching Evidence

When issuing punishments, you can attach evidence such as:

  • Screenshots (PNG, JPG)
  • Videos (MP4, MKV)
  • Activity log entries (chat, commands)

Revoking Punishments

To revoke a punishment, view the punishment details and click "Revoke". Note that expired punishments cannot be revoked.

Punishment details screenshot placeholder

Automod Rules

Automod automatically moderates chat based on configurable rules. Configure word filters, spam detection, caps filtering, and more.

Rule Types

  • Word Filter - Block specific words or phrases
  • Regex Filter - Advanced pattern matching
  • Spam Detection - Detect and block spam messages
  • Caps Filter - Limit excessive capital letters
  • Link Filter - Block or whitelist URLs

Actions

When a rule is triggered, you can configure actions like:

  • Block the message
  • Warn the player
  • Mute or ban automatically
  • Alert staff
Automod rules screenshot placeholder

Anticheat Integration

ModereX integrates with popular anticheats like Grim to provide unified alert management and automatic actions.

Alert Configuration

For each anticheat check, you can configure:

  • Alert Level - Off, Toast, Alert Bar, or Urgent
  • Threshold - Minimum violation level before alerting
  • Auto-actions - Automatic kick/ban at high VL
Anticheat alerts screenshot placeholder

Activity Logs

Activity logs provide a complete audit trail of all server events and staff actions.

Log Types

  • Chat Logs - All player messages
  • Command Logs - Commands executed by players
  • Punishment Logs - Bans, mutes, warns issued
  • Automod Logs - Rules triggered
  • Session Logs - Player joins and leaves
Activity log screenshot placeholder

Staff Chat

Staff Chat allows you to communicate with other staff members both in-game and on the web panel in real-time.

Features

  • Real-time messages between panel and in-game
  • Message history (last 100 messages)
  • Sound notifications (configurable)
  • Markdown formatting support
Staff chat screenshot placeholder

Configuration

The Configuration page allows you to manage server-wide settings.

Available Settings

  • Chat Controls - Disable chat, enable slowmode
  • Server Lockdown - Prevent new players from joining
  • Command Blacklist - Block specific commands
  • Warning Escalation - Auto-escalate warnings
  • Mute Restrictions - What muted players can do
Configuration page screenshot placeholder

Troubleshooting

Common Issues

Panel shows "Disconnected" or "Server Offline"

Check that the Minecraft server is running and the ModereX plugin is loaded. The web server runs on port 8080 by default.

Can't authenticate / Invalid token

Clear your browser's local storage and refresh the page to get a new token. Make sure you have the moderex.webpanel permission.

Changes not saving

Check the browser console for errors. If using gateway mode, ensure the connection to the gateway server is stable.

Missing features or buttons

Some features require specific permissions. Contact your server administrator if you need additional access.

Getting Help

If you need further assistance, click the Discord button in the bottom-right corner to join our support servers.
